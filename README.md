# Natural Language Instruction Planner & Executor

This repository contains a Python implementation of a natural language instruction planner and executor. The system takes natural language instructions, parses them into a sequence of tool calls (a "plan"), and then executes that plan step by step.

## Overview

The project consists of two main components:

1. **Planner**: Parses natural language instructions and generates a plan of tool calls.
2. **Executor**: Takes the generated plan and executes it step by step.

## Usage

### Basic Usage

```python
from planner_executor import Planner, Executor

# Define your tools
tools = {
    'sum': lambda a, b: a + b,
    'subtract': lambda a, b: a - b,
    'multiply': lambda a, b: a * b,
    'divide': lambda a, b: a / b
}

# Create planner and executor instances
planner = Planner(tools)
executor = Executor(tools)

# Process a natural language instruction
instruction = "add 20 and 30, divide it by the sum of 2 and 3"
plan = planner.generate_plan(instruction)
result = executor.execute_plan(plan)

print(f"Instruction: '{instruction}'")
print(f"Plan: {plan}")
print(f"Result: {result}")
```

## How It Works

### Planner

The `Planner` class takes natural language instructions and parses them into a sequence of tool calls. Each tool call is represented as a dictionary with the following structure:

```python
{
    'tool': 'tool_name',  # Name of the tool to call
    'args': {  # Arguments to pass to the tool
        'arg1': value1,
        'arg2': value2,
        # ...or references to previous results
        'arg3': {'ref': 'previous_result_id'}
    },
    'result_id': 'result_identifier'  # ID to reference this result in later steps
}
```

### Executor

The `Executor` class takes the plan generated by the `Planner` and executes it step by step. It resolves references to previous results and executes each tool with the resolved arguments.

## Extending the System

### Adding New Tools

To add new tools, simply add them to the `tools` dictionary:

```python
tools = {
    'sum': lambda a, b: a + b,
    'subtract': lambda a, b: a - b,
    'multiply': lambda a, b: a * b,
    'divide': lambda a, b: a / b,
    'square': lambda x: x * x,  # New tool
    'sqrt': lambda x: x ** 0.5  # New tool
}
```

### Enhancing the Planner

The current planner implementation uses simple string parsing to handle specific patterns. To make it more robust, you could:

1. Use regular expressions for more complex pattern matching
2. Implement a grammar-based parser
3. Integrate with an LLM for more sophisticated natural language understanding
